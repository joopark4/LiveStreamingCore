# LiveStreamingCore 쉽게 이해하기

> 📱 이 문서는 개발자가 아닌 분들도 이해할 수 있도록 작성되었습니다.

---

## 📌 한 줄 요약

**LiveStreamingCore**는 아이폰/아이패드 화면을 유튜브, 트위치 같은 플랫폼에 **실시간으로 방송**할 수 있게 해주는 **부품(모듈)**입니다.

---

## 🎯 이 모듈이 해결하는 문제

### 라이브 스트리밍을 직접 만든다면?

라이브 스트리밍 앱을 처음부터 만든다고 상상해보세요:

```
❌ 직접 만들어야 하는 것들:

1. 화면을 캡처하는 기능
2. 영상을 압축하는 기능 (1초에 수백MB → 수KB)
3. 인터넷으로 전송하는 기능
4. 유튜브/트위치와 연결하는 기능
5. 끊김 없이 보내는 기능
6. 화질 자동 조절 기능
7. 오류 복구 기능
   ... 등등 수십 가지
```

### LiveStreamingCore를 사용하면?

```
✅ 이미 만들어져 있음!

개발자: "유튜브에 연결해줘"
모듈:   "네, 연결했습니다"

개발자: "화면 방송 시작해줘"
모듈:   "네, 방송 중입니다"

개발자: "방송 중지해줘"
모듈:   "네, 중지했습니다"
```

## 🎬 라이브 스트리밍이란?

### 일반 동영상 vs 라이브 스트리밍

| 구분 | 일반 동영상 | 라이브 스트리밍 |
|------|-----------|----------------|
| **비유** | 📬 택배 (미리 포장해서 배송) | 📞 전화 (실시간 대화) |
| **제작** | 촬영 → 편집 → 업로드 → 시청 | 촬영하면서 바로 시청 |
| **지연** | 없음 (원할 때 시청) | 2~10초 정도 |
| **예시** | 유튜브 동영상, 넷플릭스 | 유튜브 라이브, 트위치 |

### 실시간으로 보내려면?

```
📱 스마트폰                    ☁️ 인터넷                    👥 시청자

[화면 촬영]  ─────────────▶  [유튜브 서버]  ─────────────▶  [시청]

   1초에 30장의             데이터를 쪼개서            받은 데이터를
   사진을 찍음               인터넷으로 전송            영상으로 재생
```

## 🔄 데이터는 어떻게 흘러가나요?

### 1단계: 화면 캡처

```
┌─────────────────────────────────────────────────────────────┐
│                      📱 스마트폰 화면                         │
│  ┌──────────────────────────────────────────────────────┐  │
│  │                                                       │  │
│  │     게임 화면, 앱 화면, 또는 카메라 화면              │  │
│  │                                                       │  │
│  │              ↓ 1초에 30번 캡처                        │  │
│  │                                                       │  │
│  └──────────────────────────────────────────────────────┘  │
│                           ↓                                 │
│                    [사진 30장/초]                            │
│                                                             │
│   💡 비유: 영화도 사진을 빠르게 보여주는 것과 같아요!       │
└─────────────────────────────────────────────────────────────┘
```

**쉬운 설명:**
- 화면을 **1초에 30번** 찍어서 사진으로 만듭니다
- 이 사진들을 빠르게 보여주면 "동영상"처럼 보입니다
- 영화관 영화도 1초에 24장의 사진을 보여주는 거예요!

---

### 2단계: 압축 (인코딩)

```
┌─────────────────────────────────────────────────────────────┐
│                       🗜️ 압축 과정                           │
│                                                             │
│   [원본 사진 30장]          →        [압축된 데이터]         │
│                                                             │
│   📦 크기: 약 100MB/초               📦 크기: 약 0.3MB/초    │
│                                                             │
│   ❌ 이대로 보내면                   ✅ 이 정도면              │
│      인터넷이 감당 불가                 인터넷으로 전송 가능   │
│                                                             │
│   ────────────────────────────────────────────────────────  │
│                                                             │
│   💡 비유: 여행 가방에 옷을 압축팩으로 줄이는 것과 같아요!   │
│                                                             │
│   🔧 사용 기술: VideoToolbox (아이폰 전용 하드웨어 칩)       │
│      - 배터리 적게 사용                                      │
│      - 발열 적음                                             │
│      - 매우 빠름                                             │
└─────────────────────────────────────────────────────────────┘
```

**쉬운 설명:**
- 원본 영상은 **너무 커서** 인터넷으로 보낼 수 없어요
- **압축**하면 크기가 **300분의 1**로 줄어듭니다
- 아이폰에는 **전용 칩**이 있어서 빠르고 효율적으로 압축해요

---

### 3단계: 인터넷 전송 (RTMP 프로토콜)

```
┌─────────────────────────────────────────────────────────────┐
│                    🌐 인터넷 전송                            │
│                                                             │
│   📱 스마트폰                                               │
│       │                                                     │
│       │  압축된 영상 데이터                                 │
│       │  (0.3MB/초 = 2.5Mbps)                              │
│       │                                                     │
│       ▼                                                     │
│   ════════════════════════════════════════                  │
│   ║  RTMP 프로토콜 (Real-Time Messaging Protocol)  ║       │
│   ║  - 실시간 전송에 특화된 통신 규약              ║       │
│   ║  - 유튜브, 트위치가 사용하는 표준              ║       │
│   ════════════════════════════════════════                  │
│       │                                                     │
│       ▼                                                     │
│   ☁️ 유튜브/트위치 서버                                     │
│       │                                                     │
│       ▼                                                     │
│   👥 전 세계 시청자                                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**쉬운 설명:**
- **RTMP**는 "실시간 영상 전송 규약"이에요
- 유튜브, 트위치, 페이스북 라이브가 모두 이 방식을 사용해요
- 마치 **고속도로**처럼, 영상이 빠르게 서버로 이동해요

---

### 4단계: 모니터링

```
┌─────────────────────────────────────────────────────────────┐
│                    📊 실시간 모니터링                        │
│                                                             │
│   방송 중 계속 확인하는 것들:                               │
│                                                             │
│   ┌─────────────────────────────────────────────────────┐  │
│   │  📈 전송 속도: 2,500 kbps (정상)                    │  │
│   │  🎞️ 프레임: 30 fps (정상)                          │  │
│   │  ⏱️ 지연시간: 3초 (정상)                            │  │
│   │  📶 네트워크: WiFi (양호)                           │  │
│   │  🔋 배터리: 85%                                     │  │
│   └─────────────────────────────────────────────────────┘  │
│                                                             │
│   ⚠️ 문제 발생 시 자동 대응:                                │
│                                                             │
│   네트워크 느려짐 → 화질 자동 낮춤 (끊김 방지)              │
│   연결 끊김 → 자동 재연결 시도                              │
│   오류 발생 → 복구 시도 또는 알림                           │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**쉬운 설명:**
- 방송 중에 **계속 상태를 확인**해요
- 문제가 생기면 **자동으로 해결**하려고 시도해요
- 사용자에게 **현재 상태를 알려줘요**

## 📊 용어 설명

| 용어 | 쉬운 설명 | 비유 |
|------|----------|------|
| **라이브 스트리밍** | 실시간으로 영상을 보내는 것 | 전화 통화 (실시간) |
| **RTMP** | 영상을 보내는 통신 규약 | 택배 회사의 배송 규칙 |
| **비트레이트** | 1초에 보내는 데이터 양 | 수도관의 물 양 |
| **프레임레이트** | 1초에 보여주는 사진 수 | 애니메이션 장수 |
| **인코딩** | 영상을 압축하는 것 | 옷을 압축팩에 넣기 |
| **해상도** | 화면의 선명도 (픽셀 수) | 모자이크 조각 개수 |
| **지연시간** | 실제와 방송 사이의 시간차 | 국제전화 딜레이 |
| **스트림 키** | 방송 채널 접속 비밀번호 | 집 열쇠 |
